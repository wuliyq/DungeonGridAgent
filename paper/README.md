# Final paper checklist

The final report is due December 2. It must use an official conference LaTeX style, fit within four pages excluding references, and include the team members’ names and PIDs.

Before writing the paper, add the chosen official template here. The paper should contain:

1. problem and motivation;
2. related work;
3. environment and Q-learning method;
4. evaluation against the random baseline;
5. limitations, including partial observability and a fixed training map.

The final repository must include both LaTeX source and compiled PDF.
